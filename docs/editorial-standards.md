# Editorial Standards (Val's House Rules)

The write-up conventions Val enforces as hard-gate reviewer. Break these and the deck comes
back.

## Bullet structure

- **Bullet 1 — volume trend.** Overall volume trend for each competitor, quantified, **starting
  with Ford**. Use **brand + model** on first mention ("Ford Explorer"), then just the model name
  thereafter. The **carline is named first**, before any competitor.
- **Bullet 2 — key drivers.** Top mentions driver for Ford by platform (often news or forums),
  then the same for the competitor with the largest volume growth. Competitor driver
  explanations are **brief — one phrase, not multi-clause**.
- **Bullet 3 — sentiment.** Only if there's something specific to say (including clusters,
  i.e. drivers with volume < 30).

## Standard phrases

- When negative sentiment is fragmented / no negative driver reaches 30 mentions, use the exact
  wording: **"no clusters of issues were identified as drivers"**.

## Sentiment bullets

- Cite **actual mention counts alongside percentages**, not just percentage-point increments.
- Small MoM deltas (**under ~5%**) don't need explicit numbers.
- **"Broadly flat" is inappropriate** when sentiment has shifted meaningfully in *relative*
  terms — describe the real movement.

## Sources & hyperlinks

- Hyperlinked sources throughout; **inline hyperlinks within bullets**.
- Top-3 named stories per bullet get a real URL.
- Prefer the cleanest domain (e.g. `finanznachrichten.de` over a regional `24hamburg.de`).
- Hyperlink formatting: linked phrase **bold** (`b="1"`); no explicit colour/underline `rPr` —
  PowerPoint applies the theme hyperlink colour and underline automatically when
  `<a:hlinkClick>` is present.

## Notes vs slide

- Overflow goes in the **slide notes**: extra mentions drivers, country breakdowns, etc.
- Val is especially interested in **country breakdowns of platform mentions** — usually too bulky
  for the slide, so keep them in notes. Break a story down by country if it has **> ~30 mentions
  in any single country**.

## Competitor changes

Write insights for competitor lines with **major** changes (up or down) vs last month — only the
major ones. If there's no room on the slide, put them in the notes.

## Sentiment consistency (Val will catch this)

Any sentiment change must appear in **both** the chart *and* Brandwatch (via the item filter
widget at the bottom of each dashboard). All passing mentions must be neutral.
